Rules of the road

ARK write boundary

  • Все записи — через @kosmos/ark или ark_core::db.
  • Прямые SQL writes в app services запрещены.
  • Dashboard — read-only.
  • Перед правками data path: bun run ark:guard:writes.

Test DB isolation

  • Никогда не указывай тестам user ARK DB.
  • Используй .tmp, .e2e, .agent/tasks/<TASK>/, OS temp.
  • Smoke: bun run ark:smoke.

Proof loop

  • .agent/tasks/<DATE>-<slug>/spec.md → реализация → evidence.{md,json} → если не PASS → problems.md → fix → reverify.
  • Каждый AC должен быть PASS, иначе таск не закрыт.
