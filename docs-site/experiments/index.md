# Эксперименты

Здесь живут результаты направленных экспериментов: «попробовали технологию X /
архитектуру Y / подход Z, замерили, приняли решение». Каждый эксперимент
самодостаточен: гипотеза → методология → цифры → вывод → ссылка на код.

Эксперимент в постоянной документации зафиксирован, потому что **результаты
имеют срок годности**: через год кто-то снова придёт с вопросом «а не пора ли
на Tauri», и без записи мы повторим работу. Запись — это вакцина от повторных
циклов «слышал-что-якобы-лучше».

## Как добавлять новый эксперимент

1. Создать `docs-site/experiments/<short-slug>.md`.
2. Структура: **Гипотеза → Методология → Замеры → Вывод → Артефакты (ссылки на ветку/PR)**.
3. Добавить строку в таблицу выше.
4. Сослать из релевантных concept-страниц (`/concepts/architecture`, `/guide/tooling` и т.п.).
5. Прогнать `bun run docs:sync` чтобы AGENTS.md/CLAUDE.md обновились.
6. Артефакты эксперимента (код, замеры) живут **в отдельной ветке** (например,
   `kosmos-tauri-test`), не в `main`. Сама страница эксперимента в main
   содержит сублимат — гипотезу, методологию воспроизведения, цифры и вывод.
   После принятия решения ветка обычно удаляется; знание остаётся здесь.
