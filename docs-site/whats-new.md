# Что нового

История изменений Kepler — для тех, кто пользуется, а не пишет код.
Сверху — самое свежее. Технические детали для разработчиков
живут в [CHANGELOG.md](https://github.com/ksanrse/kepler/blob/main/CHANGELOG.md).

## Май 2026

### Фокус без UAC <Badge type="tip" text="0.1.21" />

Раньше каждый запуск pomodoro с блокировкой сайтов спрашивал права администратора. Теперь — **только один раз за всё время**.

При первом включении блокировки Kepler установит маленький фоновый сервис, который сам управляет hosts-файлом. Все последующие сессии — без UAC, без задержки, без отвлечения.

Если случайно отменишь установку — не страшно: в **Настройки → Фокус → Системный демон** есть кнопка «Установить» с понятным статусом (работает / не установлен).

---

### Раскладные команды у каждого приложения <Badge type="tip" text="0.1.20" />

Открой launcher (`Alt+Space`) и набирай — теперь каждое расширение приносит свои команды:

- **Eden**: «Открыть Eden», «Создать заметку», «Открыть сегодняшнюю заметку»
- **Horologion**: «Открыть Horologion», «Pomodoro», «Секундомер»
- **Delphi**: «Открыть Delphi», «Inbox»
- **Arrancador**: «Открыть Arrancador»

Если запустишь action-команду (например, «Старт pomodoro») у не открытого приложения — Kepler сам поднимет его и выполнит. Никаких «упс, открой сначала окно».

---

### Eden: дневник одной кнопкой

- **«Открыть сегодняшнюю заметку»** — команда в launcher'е, которая создаёт (или открывает) заметку с датой `2026-05-19` в системном типе «Дневник». Без щелчков по сайдбару.
- **Zen-mode** — `Ctrl+K Z` или иконка спирали в titlebar. Только текст, ничего лишнего, acrylic-фон, счётчик символов внизу.
- **Dock-corner** — двойной клик по заголовку в zen-mode сжимает окно в правый нижний угол поверх остальных окон. Удобно, когда печатаешь во время созвона.
- **Контекстное меню** в сайдбаре — ПКМ на заметке → «Удалить».
- **Хоткеи работают на любой раскладке** — `Ctrl+K Z` срабатывает и на русской, и на английской.

---

### Pomodoro с блокировкой отвлекающих сайтов

В Horologion при старте pomodoro можно выбрать blocklist — Kepler заблокирует выбранные домены на время сессии. После break — автоматически снимает.

Списки доменов настраиваются в **Настройки → Фокус** — пиши руками, копируй из .txt-файла, или ссылайся на другой blocklist через `@id`.

---

### Маркетплейс расширений

В **Настройки → Расширения** теперь есть встроенный каталог: смотришь список доступных расширений, нажимаешь «Установить» — Kepler сам скачивает `.kext` и устанавливает. Обновления тоже там — кнопка «Проверить обновления» в подвале вкладки.

---

### Глобальный хоткей и tray <Badge type="tip" text="0.1.8" />

- **`Alt+Space`** — открыть launcher из любого приложения.
- В **Настройки → Общие** можно переписать хоткей: жмёшь на поле, нажимаешь свою комбинацию, всё.
- **Иконка в трее** с пунктами «Открыть» / «Настройки» / «Выход» — закрытие крестиком сворачивает в трей, не убивает процесс.

---

### Update banner в launcher

Когда обновление скачано — над списком команд появляется широкая плашка с заголовком и кратким описанием изменений. Один клик — устанавливается и перезапускает. Нет — продолжаешь работать, обновится при следующем запуске.
