# Arrancador — игры

Универсальная библиотека для игр из разных лаунчеров.

## Что умеет

- **Сканер** — находит игры Steam (VDF/ACF) и Epic Games (JSON manifests)
- **Запуск** — `steam://rungameid/<id>` или прямой `.exe`
- **Метаданные RAWG** — поиск + применение в библиотеку
- **SQOBA backup** — бэкап сейвов (zip с метой), restore, rotation keep N=10

## Открыть

- Поисковик → `arrancador`
- Команда `game: библиотека`
