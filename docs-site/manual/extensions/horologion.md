# Horologion — время

Таймеры и focus widget.

## Что умеет

- **Pomodoro** — 25/50 минут работы + перерыв
- **Stopwatch** — свободный таймер
- **Focus widget** — Spotify-mini-player-style плавающее окно с активной
  сессией. Остаётся видимым поверх всего, тикает даже когда окно
  Horologion закрыто
- **Live в фоне** — закрытие окна не останавливает таймер

## Открыть

- Поисковик → `horologion`
- Команды: `pomodoro: 25`, `pomodoro: 50`, `stopwatch: старт`
