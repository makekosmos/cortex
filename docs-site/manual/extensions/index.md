# Встроенные расширения

Расширения — отдельные приложения внутри Kosmos. Сейчас встроенных четыре:

| Расширение | Что делает |
| --- | --- |
| [**Eden**](./eden) | Заметки с rich-text редактором (TipTap), wikilink'и, ссылки на задачи |
| [**Delphi**](./delphi) | Задачи в Linear-стиле, 5 статусов |
| [**Horologion**](./horologion) | Pomodoro + stopwatch + focus widget |
| [**Arrancador**](./arrancador) | Игровая библиотека (Steam, Epic) + бэкапы сейвов |

Все расширения работают с одной общей базой ARK — данные не дублируются,
видны друг другу мгновенно.
