# Delphi — задачи

Менеджер задач с пятью статусами в духе Linear.

## Статусы

| Статус | Когда использовать |
| --- | --- |
| **Triage** | Новая задача, ещё не сортирована |
| **Backlog** | Когда-нибудь, не сейчас |
| **Todo** | Готова к работе |
| **Done** | Завершена |
| **Canceled** | Отменена |

## Что умеет

- Live sync с Eden — задача, созданная в заметке, появляется в Delphi мгновенно
- Вкладка **Сегодня** — задачи на сегодня
- Вкладка **Когда-нибудь** — backlog

## Открыть

- Поисковик → `delphi`
- Команда `task: создать`
- Команда `task: сегодня` — открыть список на сегодня
