# Kosmos

## Мануал <span class="beta-pill">β</span>

Kosmos — место, которое унифицирует хранение всех твоих данных:
**здоровье, продуктивность, мысли**. Пока только [Windows ⓘ](./platforms),
с планами на другие платформы.

Предлагается использовать Kosmos чтобы:

- запускать приложения и переключаться между ними,
- искать файлы,
- управлять окнами,
- хранить сниппеты,
- вести заметки, задачи, фокусные сессии,
- — и многое из того, что обычно раскидано по 10 разным инструментам.

По сути это попытка сделать **удобное использование компьютера через
клавиатуру и голос**. Сейчас готова только часть — но это идея, к которой
Kosmos движется.
