# Kosmos Manual <span class="beta-pill">β</span>

Kosmos — местo, которое унифицирует хранение всех твоих данных:
**здоровье, продуктивность, мысли**. Пока только [Windows](./platforms),
с планами на macOS, Android и iOS.

Предлагается использовать Kosmos, чтобы запускать приложения, искать
файлы, управлять окнами, хранить сниппеты, вести заметки, задачи и
фокусные сессии. По сути — попытка сделать удобное использование
компьютера через **клавиатуру и голос**.
