# Платформы

## Сейчас

- **Windows** 10 (build 1809+) и Windows 11 — единственная официально
  поддерживаемая платформа.

## В планах

| Платформа | Статус |
| --- | --- |
| **macOS** | в планах, следующая по приоритету |
| **Android** | в планах, после macOS |
| **iOS** | в планах, после Android |

Точных сроков нет — это личный проект, и порядок зависит от того, на
каком устройстве я сам начну спотыкаться об отсутствие Kosmos.
