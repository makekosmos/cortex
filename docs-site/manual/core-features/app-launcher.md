# Запуск приложений

Открой поисковик через **Alt+Space**, начни печатать имя приложения и нажми **Enter** — оно откроется. Никаких ярлыков на рабочем столе, никаких походов в меню «Пуск».

## Что попадает в список

Все приложения, которые ты видишь в меню «Пуск», и всё установленное из Microsoft Store. Десктопные программы вроде VS Code, Chrome, Discord — рядом со встроенными UWP-приложениями типа Калькулятора и Терминала.

## Как искать

Печатаешь — список фильтруется в реальном времени. Совпадения по началу имени всегда наверху, потом совпадения посередине. Можно искать на русской раскладке для приложений с русскими именами.

## После установки нового приложения

Перезапусти Kepler (через трей или закрытие лаунчера + новое открытие) — оно появится в списке.

---

В будущем — список свежеустановленных программ обновится автоматически. И в поисковике появятся также игры из Steam / Epic и приложения из других источников.
