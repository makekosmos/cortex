# Запуск приложений

Лаунчер Kosmos индексирует установленные приложения и позволяет запускать
их по части имени.

## Как работает

1. Нажми `Alt+Space` — откроется поисковик.
2. Начни печатать имя — список фильтруется в реальном времени.
3. `Enter` — запуск.

> 🚧 Скриншоты и список покрытых источников (Start Menu, UWP, Steam, …)
> появятся скоро.
