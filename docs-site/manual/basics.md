# Основы

Главная точка входа в Kosmos — **поисковик** (лаунчер). Вызывается
горячей клавишей `Alt+Space`.

## Что умеет поисковик

- Запускать установленные приложения
- Открывать встроенные расширения (Eden, Delphi, Horologion, Arrancador)
- Запускать команды расширений (например — `pomodoro: 25` или `note: создать`)
- Открывать настройки и dashboard

## Навигация

- `↑` / `↓` — выбор пункта
- `Enter` — запустить
- `Esc` — закрыть поисковик
