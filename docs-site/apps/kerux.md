- **Path**: `apps/kerux` (зарезервировано)
- **Аналог**: [Superwhisper](https://superwhisper.com/) — нажал хоткей, продиктовал, получил расшифровку, вставленную в активное окно.
- **Имя**: греч. κῆρυξ — глашатай.

## Идея

Глобальный хоткей → запись с микрофона → расшифровка через Whisper → результат уходит в буфер обмена / печатается в активное окно. Несколько **пресетов** под разные сценарии (быстрая надиктовка в Eden, голосовой prompt для чата, форматированная заметка, и т.д.) — пресет определяет модель, language, post-processing и куда отдать результат.

## Движки расшифровки

Два сменных backend'а:

- **Локально** — [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (CTranslate2-биндинг Whisper). Работает офлайн, без сети.
- **Облако** — `whisper-large-v3` через [Groq](https://groq.com/) API. Быстрее и точнее, но требует ключ и интернет.

Пресет выбирает один из двух (плюс параметры: модель, язык, температуру, system prompt для post-processing).

## Что должно делать

- Глобальный хоткей (один на пресет, либо общий + radial-меню выбора).
- Indicator во время записи (минимальный HUD / tray-icon).
- VAD / автоматическая остановка по тишине (опционально).
- Post-processing через LLM (опционально, в пресете) — почистить «эээ», расставить пунктуацию, перевести.
- Вставка результата в активное окно (typing-injection) **или** в буфер обмена.
- История расшифровок как `voice_clip_obj` в ARK (опционально, для последующего поиска).

## Что НЕ делать

- ❌ Постоянная запись «всегда слушаем». Только по явному хоткею.
- ❌ Отправка аудио в облако без явного выбора облачного пресета.
- ❌ Хранение API-ключей Groq в открытом виде в SQLite — через OS keychain.
