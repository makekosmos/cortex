# Примеры баз данных

Эта папка содержит примеры баз данных для тестирования (UI + API).

## Доступные базы данных

### demo.db

Демонстрационная база данных с 500 сгенерированными событиями различных типов:
- События здоровья (шаги, сон)
- Финансовые операции
- Записи журнала настроения

### toggl_track.db (планируется)

Полная синхронизация данных из Toggl Track. Для создания:

```bash
python3 -m plugins.sync_toggl --full --output examples/toggl_track.db
```

Примечание: API Toggl на бесплатном плане имеет лимит ~100 запросов в час. При достижении лимита необходимо подождать сброса квоты.
