# Arrancador Ark Connection UI

## Summary

Сделать в `Arrancador` явный и видимый UI для текущего подключения к Ark, чтобы было понятно, какую общую базу использует приложение, и чтобы можно было вручную запустить синхронизацию игр в Ark.

## Acceptance Criteria

- AC1: Backend отдает текущую информацию о выбранной Ark DB и общем selected space.
- AC2: В настройках `Arrancador` есть видимый раздел Ark с путем к текущей Ark DB и пояснением, что используется общий selected space.
- AC3: В настройках `Arrancador` есть кнопка ручной синхронизации игр в Ark с отображением результата.
- AC4: Пользователь может открыть текущую Ark DB или ее директорию из этого раздела.
- AC5: API/tests для нового UI и IPC обновлены и проходят.
