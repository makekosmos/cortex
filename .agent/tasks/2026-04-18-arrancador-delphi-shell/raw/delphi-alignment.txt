Delphi shell alignment summary

Reference behavior in apps/delphi/ts:
- Titlebar leading area contains sidebar toggle + history controls.
- Sidebar uses persisted config with width + hidden, not simple collapse.
- Desktop shell is composed as titlebar + sidebar slot + content surface.
- Windows uses titleBarOverlay with native controls; macOS uses hiddenInset.

Arrancador now matches that contract in React/Electron form:
- AppTitlebar uses sidebar toggle + history controls and drops the old centered titlebar layout.
- Sidebar persists `{ width, hidden }` under `arrancador-sidebar-config`, supports keyboard toggle and resize handle, and uses hidden mode as the main desktop state.
- Layout composes desktop chrome as titlebar + sidebar + content surface, with mobile nav preserved separately.
- Electron window options now match Delphi's `frame/titleBarStyle/titleBarOverlay` pattern more closely.
