# Task: Arrancador React to Vue feature inventory

## Summary
Produce a complete migration inventory for `apps/arrancador`: the user-facing features that exist today, the React-specific implementation layers they currently depend on, and the concrete areas that must be ported to Vue/Vapor.

## Acceptance Criteria

- AC1: Enumerate all route-level product features currently exposed by Arrancador.
- AC2: Enumerate all shared shells, providers, stores, hooks, and UI primitive layers that are React-specific.
- AC3: Enumerate build/test/dependency replacements required for a full React -> Vue/Vapor migration.
- AC4: Reference local Vue/Vapor projects in this repo that can serve as implementation precedents.
