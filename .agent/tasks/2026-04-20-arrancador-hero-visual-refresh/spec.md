# Task: Arrancador hero visual refresh

## Goal

Refresh the Arrancador game detail hero so it drops the dotted background treatment, uses a taller rounded-bottom hero image, and presents the game title/genres with the same lower-left visual language as shared game cards from `kosmos-visuals`.

## Acceptance Criteria

- AC1: The dotted background layer behind the Arrancador game detail page is removed.
- AC2: The game detail hero image occupies about 80% of the visible viewport height and has rounded bottom corners.
- AC3: The game title and genres render inside the hero at the lower-left corner instead of below the hero block.
- AC4: The title/genres visual treatment matches the shared game-card language closely enough to read as the same family.
- AC5: Relevant Arrancador tests are updated or added for the new hero layout.
- AC6: Targeted Arrancador verification passes for the touched code.
