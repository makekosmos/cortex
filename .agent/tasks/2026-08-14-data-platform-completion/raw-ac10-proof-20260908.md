## Core planning retirement

The merged Core change archives every source row in
`canonical_migration_source_archive`, verifies completed migration and exact
identity/semantic parity, then drops the legacy `areas` and `headings` tables
atomically. Archive or semantic mismatch and a partial-drop failure both
fail closed and roll back. The authoritative object HLC fallback prevents a
missing client vector from creating a synthetic newer tombstone.

```text

  --test phase3_migration_system --test phase3_migration_objects \
  --test phase3_migration_preflight --test phase3_migration_orchestrator \
```

The retirement tests cover lossless archive, reopen/idempotence, archive and
semantic mismatch rejection, and transactional rollback of a partial drop.

## Cortex migration-recovery retirement

The merged Cortex change replaces the legacy rollback RPC with the typed
`packages.restore_migration_snapshot` operation. Recovery is exact-token and
source-set bound; a stale or mismatched token returns `NotFound` without
creating a new transaction. Null-token prepared-journal recovery is supported
by an explicit source-set fallback. Desktop recovery consumers use the typed
operation and the obsolete rollback handler is removed.
